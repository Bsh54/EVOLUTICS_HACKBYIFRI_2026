## 3. Problème(s) identifié(s)

### Problème principal
Les étudiants africains perdent un temps considérable à rechercher des opportunités professionnelles (emplois, stages, bourses, concours) en naviguant entre plus de 10 plateformes différentes (LinkedIn, Indeed, Campus France, Glassdoor, sites universitaires, etc.). Cette dispersion entraîne une perte moyenne de 5 heures par semaine et une forte probabilité de manquer des opportunités pertinentes.

### Contexte du problème
Dans le contexte actuel de l'insertion professionnelle, les opportunités sont fragmentées sur de nombreuses plateformes spécialisées. Les étudiants doivent :
- Créer et maintenir des comptes sur chaque plateforme
- Effectuer des recherches répétitives avec des critères similaires
- Vérifier régulièrement chaque site pour ne pas manquer de nouvelles offres
- Adapter manuellement leur CV pour chaque candidature sans outils d'optimisation

Cette situation crée une charge mentale importante et réduit l'efficacité de la recherche d'opportunités.

### Catégories d'étudiants touchées
- **Étudiants en fin de cycle** (Licence 3, Master 2) recherchant activement des stages ou emplois
- **Jeunes diplômés** en phase d'insertion professionnelle
- **Étudiants cherchant des bourses** pour poursuivre leurs études
- **Candidats aux concours professionnels** nécessitant une veille constante

Ce problème touche particulièrement les étudiants des universités africaines qui ont un accès limité aux réseaux professionnels et aux informations centralisées sur les opportunités.

## 4. Description de la solution

### Nom de la solution
**EVOLUTICS** (Evolution + Tactics)

### Description claire et concise
EVOLUTICS est une plateforme web tout-en-un qui centralise les opportunités professionnelles et optimise les candidatures des étudiants grâce à l'intelligence artificielle. La solution agrège automatiquement des centaines d'offres d'emplois, stages, bourses et concours provenant de multiples sources en un seul endroit, génère des CV et lettres de motivation adaptés à chaque offre, et propose des simulations d'entretiens pour maximiser les chances de succès.

### Comment la solution répond au problème
EVOLUTICS résout le problème de dispersion en :
1. **Centralisant toutes les opportunités** : Un seul point d'accès remplace 10+ plateformes différentes
2. **Automatisant la veille** : Agrégation automatique des nouvelles offres sans recherche manuelle
3. **Optimisant les candidatures** : Génération IA de CV et lettres personnalisés pour chaque offre
4. **Préparant aux entretiens** : Simulations d'entretiens avec feedback IA
5. **Suivant les candidatures** : Tableau de bord unifié pour gérer toutes les candidatures

### Valeur ajoutée par rapport aux solutions existantes
- **Gain de temps mesurable** : Réduction de 70% du temps de recherche (de 5h à 1h30 par semaine)
- **Optimisation IA** : Contrairement aux plateformes classiques, EVOLUTICS adapte automatiquement chaque CV à l'offre ciblée
- **Spécialisation étudiante** : Focus exclusif sur les opportunités pour étudiants africains (stages, bourses, concours)
- **Gratuité** : Accès gratuit pour tous les étudiants, contrairement aux services premium des plateformes existantes
- **Interface unifiée** : Une seule plateforme vs navigation entre multiples sites

## 6. Technologies utilisées

### Frontend
- **React 18** : Framework JavaScript moderne pour construire une interface utilisateur réactive et performante. Choisi pour sa popularité, sa communauté active et son écosystème riche.
- **TypeScript** : Superset de JavaScript offrant le typage statique pour réduire les erreurs et améliorer la maintenabilité du code.
- **Vite** : Build tool ultra-rapide pour le développement et la production, offrant un Hot Module Replacement instantané.
- **TailwindCSS** : Framework CSS utility-first pour un développement rapide et un design cohérent.

### Backend et Base de Données
- **Supabase** : Backend-as-a-Service (BaaS) offrant :
  - Base de données PostgreSQL hébergée et sécurisée
  - Authentification intégrée (email/password, OAuth Google)
  - API REST et Realtime automatiquement générées
  - Storage pour fichiers (CV, photos de profil)
  - Row Level Security pour la sécurité des données
  
  Choisi pour sa rapidité de développement, sa scalabilité et son modèle gratuit généreux.

### Intelligence Artificielle
- **DeepSeek API** : Modèle de langage avancé pour :
  - Génération de CV optimisés
  - Rédaction de lettres de motivation
  - Simulation d'entretiens
  - Recommandations personnalisées
  
  Choisi pour son excellent rapport qualité/prix et ses performances comparables aux modèles premium.

### Hébergement et Déploiement
- **Vercel** : Plateforme de déploiement optimisée pour React/Vite, offrant :
  - Déploiement automatique depuis GitHub
  - CDN global pour performances optimales
  - HTTPS automatique
  - Preview deployments pour chaque pull request

### Outils de Développement
- **Git/GitHub** : Contrôle de version et collaboration
- **ESLint/Prettier** : Qualité et formatage du code
- **React Query** : Gestion de l'état et du cache des données

## 9. Architecture et faisabilité technique

### Architecture générale
EVOLUTICS adopte une architecture **client-serveur moderne** avec séparation claire entre frontend, backend et services externes.

```
┌─────────────────────────────────────────────────────────────┐
│                    UTILISATEUR (Navigateur)                  │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                  FRONTEND (React + TypeScript)               │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ Opportunités │  │   Chat IA    │  │    Outils    │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                    BACKEND (Supabase)                        │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ PostgreSQL   │  │     Auth     │  │   Storage    │      │
│  │   Database   │  │  (JWT/OAuth) │  │   (Fichiers) │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
└────────────────────────────┬────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                  SERVICES EXTERNES                           │
│  ┌──────────────┐  ┌──────────────┐                         │
│  │ DeepSeek API │  │  Vercel CDN  │                         │
│  │     (IA)     │  │ (Hébergement)│                         │
│  └──────────────┘  └──────────────┘                         │
└─────────────────────────────────────────────────────────────┘
```

### Flux de fonctionnement général

#### 1. Authentification
1. L'utilisateur s'inscrit ou se connecte via email/password ou Google OAuth
2. Supabase génère un token JWT sécurisé
3. Le token est stocké localement et envoyé avec chaque requête
4. Row Level Security (RLS) de Supabase vérifie les permissions

#### 2. Consultation des opportunités
1. Le frontend charge les opportunités depuis la base de données Supabase
2. Les données sont mises en cache côté client pour performances
3. Les filtres sont appliqués côté client pour réactivité instantanée
4. Pagination pour charger uniquement les données nécessaires

#### 3. Génération de CV avec IA
1. L'utilisateur sélectionne une opportunité et clique sur "Générer CV"
2. Le frontend envoie le profil utilisateur + description de l'offre à l'API DeepSeek
3. L'IA génère un CV optimisé en format texte structuré
4. Le frontend affiche le CV avec possibilité d'édition et téléchargement PDF

#### 4. Chat conversationnel
1. L'utilisateur envoie un message dans le chat
2. Le message est envoyé à l'API DeepSeek avec le contexte de conversation
3. L'IA génère une réponse en streaming (affichage progressif)
4. L'historique est sauvegardé dans le localStorage du navigateur

### Principales contraintes techniques

#### Contraintes de performance
- **Temps de chargement** : Objectif < 2 secondes pour la page d'accueil
- **Réactivité** : Filtrage et recherche doivent être instantanés (< 100ms)
- **Streaming IA** : Affichage progressif des réponses pour meilleure UX

#### Contraintes de sécurité
- **Authentification** : Tokens JWT avec expiration automatique
- **Protection des données** : Row Level Security sur toutes les tables Supabase
- **Validation des entrées** : Sanitization côté frontend et backend
- **HTTPS obligatoire** : Toutes les communications chiffrées

#### Contraintes de coût
- **API IA** : Limitation du nombre de requêtes pour utilisateurs gratuits
- **Stockage** : Limitation de la taille des fichiers uploadés (CV, photos)
- **Bande passante** : Optimisation des images et assets

### Risques techniques éventuels

#### Risques identifiés et solutions

| Risque | Impact | Probabilité | Solution |
|--------|--------|-------------|----------|
| Surcharge API IA | Élevé | Moyen | Rate limiting + cache des réponses fréquentes |
| Panne Supabase | Élevé | Faible | Backup automatique + migration vers autre BaaS possible |
| Performances avec 10 000+ utilisateurs | Moyen | Élevé | Optimisation requêtes + CDN + lazy loading |
| Coût API IA trop élevé | Élevé | Moyen | Modèle freemium + quotas + alternative API moins chère |
| Sécurité des données utilisateurs | Élevé | Faible | RLS Supabase + audits réguliers + conformité RGPD |

#### Stratégies d'atténuation
- **Tests de charge** : Simulation de 1000+ utilisateurs simultanés avant lancement
- **Monitoring** : Suivi en temps réel des performances et erreurs (Sentry)
- **Backup automatique** : Sauvegarde quotidienne de la base de données
- **Documentation technique** : Architecture et code bien documentés pour maintenance

### Faisabilité technique
Le projet est **techniquement réalisable** avec les technologies choisies. Le prototype fonctionnel actuel démontre la viabilité de l'architecture. Les principales technologies (React, Supabase, DeepSeek) sont matures et éprouvées. Le déploiement sur Vercel garantit une scalabilité automatique. Les risques identifiés sont maîtrisables avec les solutions proposées.
